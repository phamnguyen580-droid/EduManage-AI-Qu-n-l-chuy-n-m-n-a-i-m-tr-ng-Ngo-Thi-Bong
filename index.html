EduManage AI V6

Lõi backend quản lý hồ sơ chuyên môn trường học – Python thư viện chuẩn + SQLite

Giới thiệu

Máy chủ API quản lý vòng đời hồ sơ (kế hoạch bài dạy, kế hoạch giáo dục, biên bản, phiếu dự giờ, báo cáo) qua các bước: giáo viên nộp → tổ trưởng rà soát → ban giám hiệu duyệt. Quyền được kiểm tra ở máy chủ cho mọi API.

Chạy nhanh

python3 server.py init-admin admin
python3 server.py 8000
python3 test_server.py

Cần Python 3.9+. Không cần cài thêm gói nào.

Vai trò

MãVai tròQuyền chính
gvGiáo viênTạo, nộp, thu hồi, nộp phiên bản mới
ttTổ trưởngRà soát, ghi phiếu rà soát, chuyển chờ duyệt
bghBan giám hiệuDuyệt, từ chối, yêu cầu chỉnh sửa
adQuản trịTạo/khóa tài khoản, sao lưu

Bảo mật

PBKDF2-SHA256 200.000 vòng, token lưu dạng băm, khóa đăng nhập sau 5 lần sai, khóa lạc quan chống xung đột, nhật ký kiểm toán đầy đủ.

Trang này chỉ là trang giới thiệu tĩnh; GitHub Pages không chạy được server.py.
